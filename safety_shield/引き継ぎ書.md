# SAFETY SHIELD 引き継ぎ書

最終更新: 2026-10-09 / ブランチ `claude/epic-tesla-k7y1yq`(最新コミット: 768p対応・吹き出し修正・目が合ったら交戦)

## 1. これは何か

タイキ薬品工業の安全衛生委員会パトロール員8名(最大3チーム)に経路と指示を描き、「作戦実行」後はオートランで決着がつくブラウザゲーム。Rainbow Six 3: Raven Shield のプランニングモードだけを抜き出したイメージ。全5面。工場員側のモードはない(工場員はすべてAI)。

- 遊べる版(claude.ai アーティファクト、非公開): https://claude.ai/artifact/UcmJBDNeNS7Nr72qeB98WW
- 企画書(Claude Docs): https://claude.ai/code/artifact/5ef2f362-bdd7-4f83-a5d4-8c4a1a4da8cf
- ソース: リポジトリ `purim-sakamoto/claude` の `safety_shield/`

```

  js/data.js        隊員8名・携行品・敵タイプ・5面のマップと目標・セリフ
  js/sim.js         シミュレーション本体(描画から独立・決定論的。Nodeでも動く)
  js/game.js        画面・入力・描画・チュートリアル・遊び方ダイアログ
  build.js          CSS/JSを埋め込んだ1ファイル版を出力
```

## 4. 動かし方・確認方法

- 遊ぶ: `index.html` をブラウザで開く(または1ファイル版 `safety_shield.html`)。フォントは Google Fonts から読む。オフラインでも代替フォントで動く。
- 1ファイル版を作る: `node build.js 出力先.html`(アーティファクト用は `--fragment` を付ける。`<html>` などを付けない形になる)
- テスト(Node 18以上):
  ```
  node test/validate.js   # 「OK」で終わればマップ整合性に問題なし
  node test/auto.js 40    # 各面のおまかせ勝率
  node test/tactics.js 40 # 合図+ライトの勝率
  ```
- 保存: 進行状況・各面のプラン・チュートリアル済みフラグは localStorage(キー接頭辞 `ss_`。プランは `ss_plan2_<面番号>`)。最初からやり直すときは `ss_` で始まるキーを消す。

## 5. ゲームの仕組み(sim.js)

- 0.1秒固定ステップ。シード付き乱数なので、同じプラン+同じシードなら同じ展開になる(「同じシードで再生」はこれを利用)。
- マップは ASCII(1文字=1マス、36×24)。記号の意味は `data.js` 冒頭のコメントを参照。
- **チーム移動**: リーダーが A* 経路を進み、残りは軌跡を追う。地点を使い切ったら(地点ゼロでも)**おまかせ巡回** `autoNext()` に入り、未記録の不安全箇所・制圧目標へ近い順に向かう。他チームが向かっている先は後回しにする。
- **発見**: 工場員は扇形の視界(壁・棚・施錠扉で遮られる)で隊員を見ると警戒メーターが上がる。0.4で「?」(調べに来る)、1で「!」(気づく)。
  - **互いの視界に入ったら即「!」+交戦**(4回目の要望)。
  - 足音・指摘の声などの「音」でも寄ってくる。
- **通報**: 気づいた工場員は無線で通報する。猶予は `radioTime()`(最低2秒、製造部長だけ即時)。その間に制圧するか、安全ライトでくらませると止まる。通報が回ると全員が警戒し、半径6.5マス以内の不安全箇所を片付け始める。必須の箇所は片付けに4倍の時間がかかる。
- **交戦**:
  - 指摘の仕方(内部名 ROE): こっそり=recon、慎重=infil、強気=assault。
  - 慎重は「気づいた相手」と「すぐそばの相手」にだけ指摘する。
  - 気づいていない相手が2.2マス以内なら、指摘票で静かに制圧を試みる。
  - くらんだ相手が3マス以内なら、高確率で静かに制圧できる。
  - 工場員の反撃は「誤魔化し」。当たると隊員の元気が減り、0で離脱する。
- **安全ライト**: 見えている一番近い工場員 → 次の地点 → 正面、の優先順で投げ込む(半径3.2マス、5秒くらませる)。次の地点が扉の向こうなら、扉が開いた瞬間に投げる。
- **合図(Goコード)**: 同じ合図を待つ全チームが揃うと一斉に動く。
- **終了とランク**: 全員離脱 / 必須目標が達成不能 / 時間切れ / 全チーム完了 で終わる。
  - S: 全件記録・通報なし・離脱なし
  - A: 8割以上記録・離脱1名以下
  - B: 目標達成
  - D: 失敗

## 6. 難易度の調整ノブ

- 面ごと(`data.js` の各ステージ):
  - `detect`: 発見されやすさの倍率
  - `radio`: 通報までの時間の倍率
  - `conceal`: 片付け時間の倍率
  - `noise`: 足音の倍率
  - `dark`: 暗所(視界6割)
  - `objectives`: 目標
- 敵タイプ(`SS.ENEMY_TYPES`): `resolve`=粘り(体力)、`deceit`=誤魔化し力、`dmg`=反撃の強さ、`alarmT`=通報時間、`conceal`=片付け秒数。
- 全体: `sim.js` の `perception()` 内の発見係数 `2.0`、`MOVE_VIS`(歩き方ごとの目立ちやすさ。待機中は `hold` 0.15)、片付け半径 `6.5`。

現在の計測値(40シード):

| 面 | おまかせだけ | 合図待ち+ライト1回 |
| --- | --- | --- |
| 1 原料倉庫 | 100% | ― |
| 2 打錠室 | 100% | ― |
| 3 夜勤・包装ライン | 100%(ほぼランクB) | 約83% |
| 4 危険物倉庫 | 約75% | 約83% |
| 5 本社工場 製造管理棟 | 約70% | 約85% |

調整を変えたら `test/auto.js` と `test/tactics.js` を回して、上の表から大きく外れていないか確認する。

## 7. 未解決・気になっている点

- 3面は、合図+ライトを足したほうがおまかせよりわずかに勝率が下がる(テスト用の待機地点の選び方による)。工夫の効き目が4・5面ほどはっきりしない。
- 人が実際に遊んでの手触り調整はまだ。特に次の点は、プレイ感想をもとに数値を詰める想定。
  - 見つかるまでの速さ
  - 通報の猶予
  - 戦闘で元気が減る速さ
- 隊員の成長(経験値)、プラン共有コード、タイムラインプレビューは企画書にあるが未実装。
- タッチ端末では右クリックの代わりに「1つ戻す」ボタンを使う。長押しでの取り消しは未対応。

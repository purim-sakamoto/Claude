# SAFETY SHIELD ―安全パトロール制圧戦―

タイキ薬品工業の安全衛生委員会・特別パトロール班(8名)を最大3チームに分け、作戦を立てて「実行」を押したら、あとは見守るだけ。
Rainbow Six 3: Raven Shield のプランニングモードを下敷きにした、操作介入なしのオートラン型タクティカルゲーム(全5面)。

## 遊び方

`index.html` をブラウザで開く(ビルド・サーバー不要)。

1. **編成**: 8名を レッド/グリーン/ゴールド に配属(各4名まで)。携行品(安全ライト・デジカメ・合鍵)を選ぶ。
2. **経路**: 地図の床をクリックして地点を置く。地点ごとに「ここからの速度」「交戦規定」「Goコード待機」「行動」を設定。
3. **作戦実行**: 以降は一時停止と倍速のみ。勝敗はプランの質で決まる。
4. **デブリーフィング**: ランク・指摘票を確認。「同じシードで再生」で同じ展開をもう一度見られる。

## ルールの骨子

| 要素 | 内容 |
| --- | --- |
| 発見 | 工場員は視界(扇形・壁で遮蔽)で隊員を見ると警戒度が上がる。足音・指摘の声も聞かれる |
| 通報 | 気づいた工場員は数秒で無線通報。間に合わず通報が回ると全員が片付け(証拠隠し)を始める |
| 記録 | 見えている不安全箇所を見続けると記録。通報前の「素の状態」なら得点2倍 |
| 指摘 | 交戦規定に従い指摘(=射撃)。気づかれていない相手には至近で「指摘票」による静かな制圧 |
| 誤魔化し | 工場員の反撃。当たると隊員の「元気」が減り、0で離脱 |
| Goコード | 同じコードで待機する全チームが揃うと一斉に前進。突入と安全ライト投げ込みを同期できる |
| 施錠扉 | 合鍵を持つ隊員がいるチームだけ通れる(ブリーチャーは1秒、通常は3秒) |

ランク: S=全件記録・通報なし・離脱なし / A=8割以上記録・離脱1名以下 / B=任務達成 / D=失敗

## 構成

- `js/data.js` 隊員・敵タイプ・5面のマップと目標
- `js/sim.js` 決定論的シミュレーション(描画から独立。Node でも動く)
- `js/game.js` 作戦立案UI・描画・再生
- `test/validate.js` 全マップの整合性・到達可能性チェックと通し実行
- `test/balance.js` 手書きプランでの攻略可能性(20シード)の確認
- `build.js` CSS/JSを埋め込んだ1ファイル版を出力(`node build.js out.html`)

```
node test/validate.js
node test/balance.js
```

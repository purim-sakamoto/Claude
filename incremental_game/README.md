# タイキ薬品工業　ミニゲーム

ブラウザで遊ぶ放置・インクリメンタルゲームです。
最初はボタンが1つだけ。手作業から工場、タンクローリー、そして……。

- 企画・仕様：`docs/01_企画書.md`、`docs/02_要件定義書.md`、`docs/03_中盤プロセス設計書.md`
- 想定クリア期間：5〜14日（放置中も進みます）

---

## 1. いちばん簡単な遊び方（1ファイルだけ）

**`dist/taiki_minigame.html`** が、ゲームのすべてを1つにまとめたファイルです。

1. GitHub でこのファイル（`incremental_game/dist/taiki_minigame.html`）を開く
2. 右上の「ダウンロード」ボタン（↓の形、Download raw file）を押す
3. ダウンロードしたファイルをダブルクリック → Edge や Chrome で開いて遊べます

インターネット接続も、Python も、インストールも要りません。

## 2. 会社のアプリに組み込むとき

`taiki_minigame.html` を1つ置くだけで動きます。

- **リンクで開く**：ボタンのリンク先をこのファイルにする
- **アプリの画面の中に表示する（iframe）**：
  ```html
  <iframe src="taiki_minigame.html" style="width:100%; height:100vh; border:0;"></iframe>
  ```
- **デスクトップアプリ（WebView など）**：このファイルを読み込ませる

ファイルを分けたまま使いたい場合は、`index.html` と `css/`・`js/` フォルダを同じ並びのまま置けば同じように動きます。

### セーブについて
- セーブはブラウザの中（localStorage）に自動で保存されます（30秒ごと・閉じるとき）
- **ファイルを置く場所（URL）が変わると、別のセーブ扱いになります。** 引っ越すときは
  画面右上の「⚙ 設定」→ 「セーブの書き出し」で文字をコピーし、新しい場所で「セーブの読み込み」に貼り付けてください
- iframe の設定によっては保存が禁止されていることがあります（その場合はゲーム内に注意が出ます）

## 3. 画面の見かた（遊ぶ人向けのメモ）

- **カーソルを合わせると説明が出ます**（スマホは長押し）。ボタンなら「何をするか」、資源なら「あと何分で満杯／空になるか」「何が増やして何が減らしているか」
- **手作業のボタン**（鉄くずを拾う・塩酸で溶かす・店先で売る）は、押すたびにその工程を手伝い、しばらく速くなります（速く押すほど、最大 ×2）。右の資源欄の毎秒の数字は、手伝いを含まない「自動で動いている分」だけです。人や設備を動かすと、すぐに数字が変わります
- **上の細い帯**（しばらく遊ぶと出てきます）は「仕入れ → つくる → 詰める → 売る」の流れです。赤い枠が今の詰まり。その下の「手当て」ボタンを押すと、そのまま人を回したり設備を買ったりできます
- **与信枠**：お金が足りなくても、枠の中なら設備・仕入れ・給料に使えます（ボタンの値段が黄色なら借りて買える）。借りている間は利息がつき、新しい人は来ません。枠の8割を超えると上の帯で知らせ、**枠を超えたまま1分たつと設備を1つずつ手放します**（いちばん高く売れるものを半値で）
- **記録タブの帳簿**では、月ごと（ゲーム内の1か月≒約7分）の損益計算書・貸借対照表・キャッシュフロー計算書が見られます。設備・改善の代金は簿価に積んで少しずつ減価償却します
- 新しい設備・改善・技術は、一度に2〜3個ずつ現れます。買うと次が見えてきます
- **右の資源欄**は種類ごとに分かれています：原料（仕入れる）／タンクの液（つくったもの）／缶／売り物（缶・箱）／水・排水。いま売っている品には「売」の印がつきます。入る量と出る量がほぼ同じものは数字の代わりに「釣り合い」（空のまま使い切っていれば「空：入るそばから使う」）と出ます
- **缶はめぐります**：新缶を買う → 詰める → 配達 → 配達の帰りに空き缶（汚れた缶）を引き取る（9割が戻る）→ 洗う（5%は傷んで廃棄、約20回で寿命）→ また詰める。新缶は戻らなかった分の補充だけ（缶の仕入れ契約は、空き缶が置き場の3割を切ったときだけ買う）。**汚れた缶の置き場がいっぱいだと、引き取れないので配達に出られません**
- **排水**は、流せる量（そのまま流せる分＋排水桝＋中和槽・凝集沈殿槽などで処理する分）しか出せません。洗缶は1缶10Lの排水を出すので、排水が満水だと洗えず、汚れた缶があふれて出荷が止まります。最初の手当ては「ためすすぎ」（洗缶の排水半分）と「排水桝」。工場になってからは溶解・塩素化などの製造も排水を出します
- 右上の暦は創業の1946年（昭和21年）から進みます。創業50周年からは10年ごと、年商の節目（1億円、100億円…）ではログに特別な一行が流れます

## 4. 開発者モード

画面右上の「⚙ 設定」→ 「開発者モード」→ パスワード **1234**（一度入ると、同じブラウザでは次に開いたときも開発者モードのまま。「終了」で抜ける）

| 機能 | 内容 |
|---|---|
| 速度 | ×1 / ×10 / ×100 / ×1000 / ×10000 |
| お金無限 | ON の間、お金が減らない |
| お金を足す | +1万円 / +100万円 / +1億円（一度だけ足す。バランスを見ながら確かめたいとき） |
| 資源を満タン・技術+大量・人手+10 | 動作確認用 |
| 時間を進める | +10分 / +1時間 / +8時間（留守中と同じ計算） |
| 技術を全部・次の時代へ・全部見せる | 後半の画面確認用 |
| 自動プレイで計測 | ヘビー／ふつう／ライトの遊び方を自動でまねて、各時代の到達日数とクリア日数を計算する（数十秒〜数分） |
| 状態をコピー | 今のセーブ文字列をコピー |

※ パスワードは画面上の簡易な鍵です（ファイルの中に書かれているので、秘密を守るものではありません）。
※ 開発者モードはブラウザのタブを閉じると解除されます。

## 5. 数値を調整したいとき

ゲームの数値・文章は、ほぼすべて **`js/data.js`** にまとまっています（資源・設備・技術・改善・製品・物語の文章・作業メモ）。
変更したら、`dist/taiki_minigame.html` を作り直してください（下の 6.）。

## 6. 開発者向け

| ファイル | 役割 |
|---|---|
| `index.html`, `css/style.css` | 画面 |
| `js/data.js` | ゲームデータ（数値・文章） |
| `js/engine.js` | 計算（流れのモデル・市場・保存・留守中の進行） |
| `js/ui.js` | 描画 |
| `js/sim.js` | 自動プレイ（バランス計測） |
| `js/dev.js` | 開発者モード |
| `js/main.js` | 起動・ループ・エンディング |
| `tools/build_single.py` | 1ファイル版 `dist/taiki_minigame.html` を作る（`python tools/build_single.py`） |
| `tools/sim_node.js` | Node でバランス計測（`node tools/sim_node.js normal 16 -v`） |
| `tools/timeline_node.js` | 序盤に何がいつ見えてくるかを出す（`node tools/timeline_node.js 30`） |

- ビルドは不要です。`index.html` をダブルクリックすればそのまま動きます（`file://` で動くように ES Modules や外部ファイルの読み込みは使っていません）
- 自動プレイの計測は、開発者モードからブラウザだけでも実行できます

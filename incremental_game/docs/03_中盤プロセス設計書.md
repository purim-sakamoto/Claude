# 中盤プロセス設計書：『タイキ薬品工業　ミニゲーム』

> 対象：時代1〜4（工房 → 工場 → 基地 → 系）。**このゲームの肝**
> 手作業の釜から、充填コンベア・自動洗缶ライン・フォークリフト・クレーン・タンクローリー・分析室・純水装置・受託製造までを、
> **お金を稼いで再投資する**ループの中で、互いに絡み合うプロセスとして描く。

## 1. 設計思想

### 1.1 三つの原則
1. **流れで考える**：工場は「工程」と、その間の「置き場（タンク・倉庫）」の連なり。どこか一か所が詰まると、上流は溢れ、下流は干上がる
2. **ボトルネックは移動する**：一か所を直すと、次に弱い場所が露わになる。これを数十回繰り返すことが中盤の遊びそのもの
3. **全部がつながっている**：洗缶すれば排水が出る。排水は自社の凝集剤で処理する。尿素水が売れると純水が足りなくなり、分析室の水まで細る。一つの決断が三つ先の工程に響く

### 1.2 進化の四段階（どの工程にも共通）
| 段階 | 例（充填） | 例（運搬） | 特徴 |
|---|---|---|---|
| ① 手 | じょうごと はかりで手詰め | 手で持つ・台車 | 人手を食う。安い |
| ② 道具 | ハンドポンプ＋台はかり | ハンドリフト・軽トラ | 人手あたりの能力↑ |
| ③ 機械 | 半自動充填機・ベルトコンベア | フォークリフト・クレーン・トラック | 電力・資格・敷地を要求 |
| ④ 自動 | 自動小分け装置・ロボットパレタイザ | 自動倉庫・配車システム・ローリー網 | 人手が浮き、研究・品質・営業に回る |

### 1.3 有機的なつながりを生む「共有の制約」
すべての工程がこれらを**取り合う**。中盤の悩みの大半はここから生まれる。

| 共有の制約 | 取り合う工程 | 増やし方 |
|---|---|---|
| 人手 | 全工程 | 寮・採用。自動化で浮かせる |
| 有資格者 | フォーク・クレーン・ローリー・劇物・排水 | 講習に出す（時間＋円） |
| 電力 | コンベア・洗缶・純水・分析機器・冷却 | 受変電設備・契約電力の増強 |
| 敷地（床面積） | すべての設備・置き場・車庫 | 土地購入・ラック/クレーンで立体化・新工場 |
| 空き容器 | 全製品の充填 | 新品購入・返却缶の洗浄 |
| パレット | 保管・荷役・出荷 | 購入・回収 |
| 荷役能力 | 原料受入・倉庫・出荷積込 | フォークリフト台数・クレーン・自動倉庫 |
| 分析能力 | 受入検査・製品ロット判定・受託分析 | 分析機器・分析員・超純水 |
| 純水 | 尿素水・希釈調合・分析・洗缶仕上げ | 純水装置の系列を増やす |
| 配車（車両と運転手） | 製品配送・空缶回収・原料引取 | 車両・運転手・配車システム |
| 排水処理能力 | 洗缶・洗浄・分析廃液・雨水 | 中和槽・凝集沈殿・脱水機 |

## 2. 流れのモデル（計算仕様）

### 2.1 工程と置き場
```
[原料置き場] → (工程A) → [中間置き場] → (工程B) → [製品置き場] → (工程C) → ...
```
- **置き場**＝数量と上限を持つ資源（Kittens Game の資源と同じ）。例：`塩酸タンク`、`検査待ち液`、`合格液タンク`、`充填済みポリ缶（倉庫）`、`出荷待ち`、`返却缶`
- **工程**＝毎秒能力（処理量/秒）を持つ。能力は 設備数 × 配属人数 × 改善倍率 で決まる
- 各ティックで、工程の実処理量 = `min(能力, 入力置き場の在庫, 出力置き場の空き, 共有制約の割当)`
- これだけで「詰まり」「溢れ」「干上がり」が自然に起きる。特別なイベント処理は要らない

### 2.2 共有制約の配分
- 共有制約（電力・荷役・分析・純水・配車…）は、工程ごとに**優先度**（高・中・低）を設定でき、高から順に配分する
- 既定値は「出荷 ＞ 製造 ＞ 受入 ＞ 洗缶」。プレイヤーが変更できる（変更は時代2で開示）

### 2.3 バッチとロット（時代2〜）
- 製造は**バッチ**単位：反応槽1基が1回で作る量。バッチが終わると1**ロット**として `検査待ち` に入る
- ロットは分析で合格するまで出荷できない。分析能力は「ロット数/時間」で決まる
- **大きな槽ほどロット数が減る** → 分析負荷が下がる（大型化する理由が自然に生まれる）

### 2.4 ボトルネックの可視化
- 工程図（FR-FLW）で、稼働率が下がっている工程を赤、溢れている置き場を橙で表示
- 各工程のツールチップに「止まっている理由」を一言で出す：`入力不足：塩酸` `出力先満杯：検査待ち液` `電力不足` `有資格者なし`

## 3. サブシステム詳細

### 3A. 製造（溶解・反応・濃縮・希釈・調合）

| 段階 | 設備 | 能力の目安 | 要求 | 解放 |
|---|---|---|---|---|
| 手 | 壺 → 釜 | 1 | 人手 | 導入 |
| 道具 | 鉄の釜・撹拌棒 | ×3 | 人手 | 時代1 |
| 道具 | 換気扇 | 作業効率↑ | 電力（少） | 「むせる」ログの後 |
| 機械 | FRP反応槽 | ×20 | 電力・敷地 | 時代1後半 |
| 機械 | 塩素化設備 | 第一鉄→第二鉄 | 塩素・電力 | 技術「塩素化」 |
| 機械 | スクラバー | 酸ミストを回収 → **回収希塩酸**を溶解へ戻す | 電力・水 | 時代2 |
| 機械 | 濃縮設備 | 濃度グレード↑（40→42→47→50°Bé相当） | **熱**（蒸気） | 時代2 |
| 機械 | ボイラー | 蒸気 | 燃料（購入 → のちに自社の水素で一部代替） | 濃縮と同時 |
| 機械 | 希釈・調合槽 | 酸・アルカリの濃度調整、混合 | 純水 or 水道水 | 時代1後半 |
| 機械 | 溶解設備 | 固形・粉末原料の溶解（尿素など） | 加温（尿素の溶解は**吸熱**） | 時代3 |
| 機械 | 冷却設備 | 次亜塩素酸ソーダの貯蔵冷却（分解・副生成分の抑制） | 電力 | 時代3 |
| 自動 | 計装盤・DCS | 配属なしで連続運転 | 電力・研究 | 時代3〜4 |

**つながり**
- 鉄を溶かすと**水素**が出る → 換気が必須。時代4で水素回収 → ボイラー燃料 → 濃縮のコスト↓
- スクラバーは排気の酸を捕まえる → 回収希塩酸が原料に戻る（最初の「循環」）
- 濃縮は熱を食う → ボイラー → 燃料費が損益に出る

### 3B. 品質管理（分析室・純水）

**ロット判定の流れ**
`製造` → `検査待ち` →（採取・分析）→ `合格品タンク` → 充填へ ／ 不合格 → 再調整（希釈・再濃縮）へ戻す

**分析手段の進化**（各機器は「できる分析」と「解放する製品・グレード」を持つ）

| 機器 | ゲーム内の役割 | 解放・効果 |
|---|---|---|
| 目視（色） | 最初の判定。遅く不確か | — |
| 比重計（ボーメ） | 濃度の確認 | 塩化第二鉄液のグレード表示 |
| デジタル屈折率計 | **濃度の速測** | ロット判定速度↑。**尿素水の濃度管理**（32.5%） |
| 電気伝導度計 | 水の純度管理 | 純水装置の品質、純水販売 |
| 紫外可視分光光度計 | 化合物・副生成分の定量 | 品質グレード↑、クレーム率↓ |
| 原子吸光光度計 | 微量重金属の定量 | 水道・浄水場向けグレード、**使用済み液の銅濃度管理**（脱銅の効率↑） |
| イオンクロマトグラフィー | 陰イオン・陽イオンの分析 | **次亜塩素酸ソーダ中の塩素酸・臭素酸**の管理 → 浄水場向け次亜を解放 |
| ICP発光分光分析装置 | 多元素の同時分析 | 分析能力が大幅↑（1回で多項目）。尿素水の多項目分析、食品添加物グレード |
| フーリエ変換分光光度計 | 分子構造から物質を判定 | **内容不明の物質の判定** → 受託案件・不明廃液の受入を解放 |
| 粘度計 | 液の粘り | PAC・ポリ硫酸第二鉄・ポリシリカ鉄の品質管理 |

**分析用の水**（実在の製造工程に沿う）
```
水道水 → 前処理（除塵・除鉄・除塩素）→ 逆浸透膜（RO）→ イオン交換樹脂 → 紫外線殺菌 → 高純水（15 MΩ·cm）
                                                                        └→ 超純水製造装置 → 超純水（18 MΩ·cm）
```
- 高純水は**製品用の純水と前段を共有**する → 尿素水が売れるほど分析用の水が細る（有機的な衝突）
- ICP とイオンクロマトは**超純水がないと能力が大きく落ちる** → 超純水装置を別系統で建てる動機
- 各段は個別の設備（前処理器・RO膜ユニット・イオン交換塔・UV殺菌器・超純水装置）。RO膜・樹脂は**消耗品**で、定期交換コストが損益に出る

### 3C. 容器（新品・返却・洗缶）

```
[新品ポリ缶を購入] ─────────────────────────┐
                                             ↓
[返却缶] → 受入検査 → 残液抜き → 洗浄 → 乾燥 → 外観・漏れ検査 → [洗浄済み缶] → 充填へ
              │          │                          └→ 不合格 → 破砕 → 樹脂として売却（少額）
              │          └→ 残液：同じ製品なら工程へ戻す／違えば排水処理へ
              └→ 汚れがひどい → 廃棄
```
| 段階 | 設備 | 能力 | 要求 |
|---|---|---|---|
| 手 | 水場でブラシ洗い | 小 | 人手・水 |
| 道具 | 高圧洗浄機・乾燥棚 | 中 | 電力・水 |
| 機械 | 洗缶機 | 大 | 電力・水・敷地 |
| 自動 | **自動洗缶ライン**（反転・洗浄・すすぎ・乾燥・検査を一貫） | 特大 | 電力・純水（仕上げすすぎ）・排水処理 |

**つながり**
- 返却缶は、小分けで売った缶が**遅れて**（数分〜数十分）一定割合で戻ってくる。回収率は信用と「回収便」（配車）で上がる
- 新品缶は高い。洗浄缶は安いが、**洗うほど排水が増える** → 排水処理（3I）が要る
- 自動洗缶ラインに余力が出ると「**洗缶受託**」（他社の缶を洗う）を受けられる → 余力が売上になる
- 原料の塩酸がポリ缶で届く時代1では、**原料の空き缶**が最初の返却缶になる（最初の「あれ、この缶使えるのでは？」）

**荷姿（容器の種類）**
| 荷姿 | 容量 | 必要な荷役 | 特徴 |
|---|---|---|---|
| ポリ缶 | 16〜25kg | 手で可 | 単価高・手間大。小口客 |
| バッグインボックス | 10〜25kg | 手で可 | 使い捨て内袋。洗缶不要。尿素水で人気 |
| ドラム | 100〜200L | ドラムリフター／フォーク | 中口客 |
| コンテナ（IBC） | 1000〜7000L | **フォークリフト必須** | 大口客。返却・洗浄あり |
| タンクローリー | 2〜20t | ローリー充填所＋大型免許 | 単価最安・量が桁違い |

### 3D. 充填・小分けライン

ライン＝**モジュールの直列**。ライン能力＝最も遅いモジュールの能力。モジュールを一つずつ買い替えるたびに、詰まりが次のモジュールへ移る。

```
缶供給 → 充填 → キャップ締め → ラベル貼り → 重量検査 → パレット積み
```
| モジュール | 手 | 道具 | 機械 | 自動 |
|---|---|---|---|---|
| 缶供給 | 手で並べる | 台車 | **ベルトコンベア** | 自動缶供給機 |
| 充填 | じょうご＋はかり | ハンドポンプ＋台はかり | 半自動定量充填機 | **自動小分け装置**（多ノズル） |
| キャップ締め | 手 | トルクレンチ | キャッパー | 自動キャッパー |
| ラベル | 手書き | 印刷ラベル | ラベラー | ロット番号印字一体型 |
| 重量検査 | — | 台はかり抜き取り | 重量チェッカー（全数） | 自動はじき出し |
| パレット積み | 手積み | — | 半自動パレタイザ | **ロボットパレタイザ** |

- 重量検査がないと**内容量不足のクレーム**が一定確率で起き、信用が少し下がる（重量チェッカーの存在理由）
- ラベルにロット番号が入ると、クレーム時の損失が小さくなる（トレーサビリティ）
- ライン数を増やせば並列化できる（敷地・電力・人手と相談）
- ライン専用化（製品ごとに専用ライン）で切替ロスがなくなる。共用ラインは製品切替のたびに洗浄時間がかかる

### 3E. 保管・荷役

| 段階 | 設備 | 敷地あたり保管量 | 要求 |
|---|---|---|---|
| 手 | 床置き | 1 | — |
| 道具 | パレット＋ハンドリフト | 2 | パレット |
| 機械 | **フォークリフト**＋パレット | 3 | 運転技能講習の修了者・充電（電力） |
| 機械 | ラック（高積み） | 6 | フォークリフト |
| 機械 | **天井クレーン** | 重量物・ドラム・コンテナ・原料フレコンの扱いが高速に | 玉掛け・クレーン運転の有資格者 |
| 自動 | 自動倉庫 | 15 | 電力・研究 |

**荷役能力**は一つのプールで、**原料の荷下ろし・倉庫内移動・出荷の積込**が取り合う。トラックが増えると積込に荷役を取られ、原料の荷下ろしが遅れ、製造が止まる……という連鎖が起きる。

### 3F. 出荷・輸送

| 段階 | 車両・設備 | 1便の量 | 届く範囲 | 要求 |
|---|---|---|---|---|
| 手 | 手渡し・台車・リヤカー | 極小 | 近所 | — |
| 道具 | 軽トラック | 小 | 町 | 普通免許・車庫 |
| 機械 | 2tトラック → 4tトラック | 中 | 県内 | 準中型/中型免許・車庫・燃料 |
| 機械 | ユニック車（クレーン付き） | 中 | 県内 | 客先にフォークがなくても降ろせる（小口客の満足↑） |
| 機械 | ウイング車 | 大 | 地方 | 大型免許・フォーク積込 |
| 機械 | **タンクローリー**（2t → 10t → 20t） | 特大 | 地方〜広域 | 大型免許（＋けん引）・ローリー充填所・トラックスケール・出荷タンク |
| 自動 | 配車システム・中継デポ・貯蔵出荷基地 | — | 全国 | 研究・敷地（別拠点） |

**届く範囲（ゾーン）**：近所 → 町 → 県内 → 地方 → 全国。ゾーンが広がるたびに**新しい取引先**が現れる。遠いほど単価は良いが運賃（燃料・人件費）がかかる。

**配車**：車両と運転手は一つのプールで、**製品配送・空缶回収便・原料引取**が取り合う。配車係（人手）→ 配車システム（研究）で効率↑。

**ローリー出荷の一式**（時代3の大型投資）
`出荷タンク` ＋ `防液堤`（大型タンクの前提） ＋ `ローリー充填所`（ローディングアーム） ＋ `トラックスケール`（計量） ＋ `タンクローリー` ＋ `大型免許の運転手`
→ すべて揃って初めて動く。揃えるまでの数時間が「次はあれを買う」の連続になる。

### 3G. 原料受入

| 原料 | 最初 | 中盤 | 終盤 |
|---|---|---|---|
| 鉄 | 拾う（鉄くず） | スクラップ業者から購入 | 鋼材の端材を定期契約 |
| 塩酸 | 店で買う（ポリ缶） | 配達してもらう（ポリ缶→ドラム） | **ローリー受入**（受入タンク・受入検査が必要。単価が大きく下がる） |
| 塩素 | — | ボンベ | 大型容器 |
| 尿素 | — | 袋（25kg） | **フレコン（1t）** → クレーン／フォークでホッパーへ |
| 苛性ソーダ・硫酸など | — | ポリ缶・ドラム | ローリー受入 |
| 水 | 水道 | 水道（使用量に応じて料金） | 井戸・排水再生水 |
| 使用済みエッチング液 | — | 客先から引取（運賃は客持ち＝売上） | 定期回収便 |

- 受入は**受入検査**（分析能力を使う）を通って初めて原料タンクに入る
- 大口受入ほど原料単価は下がるが、タンク・防液堤・荷役・分析の先行投資が要る

### 3H. 循環とメタル精製

```
[使用済みエッチング液]（客先から引取）
     → 銅濃度の分析（原子吸光）
     → 脱銅処理設備 → [銅（粗）] → 精製 → [精製銅] → 売却／めっき分野へ
     → 再生塩化第二鉄液 → 濃度調整 → 製品へ（リサイクル品グレード）
```
- バージン品（新しい原料から）とリサイクル品（再生）の2グレード。客によって欲しい方が違う
  - 例：放流基準が厳しい地域の下水処理場 → 重金属の少ないバージン品を好む（汚泥を肥料にできる）
  - 例：電子部品の工場 → 自分の使用済み液を引き取ってくれるならリサイクル品で可、処理費が浮く
- 時代4の「循環率」の最大の構成要素

### 3I. 用役・環境（電力・蒸気・排水・排気）

| 系統 | 設備の進化 | つながり |
|---|---|---|
| 電力 | 契約電力↑ → 受変電設備 → 屋根の太陽光 | すべての機械が食う。不足すると稼働率が按分で下がる |
| 蒸気 | 小型ボイラー → 貫流ボイラー → 水素混焼 | 濃縮・尿素溶解 |
| 排水 | 中和槽 → 凝集沈殿槽 → 脱水機 → 再生水装置 | 中和に**自社の酸・苛性ソーダ**、凝集に**自社の塩化第二鉄液・ポリシリカ鉄**を使う（自社製品の自家消費）。汚泥は処分費 → のちに資源化 |
| 排気 | 換気扇 → スクラバー → 多段スクラバー | 回収希塩酸が原料に戻る |

### 3J. 人・資格・安全

**資格**：人手を講習に出す（時間＋円）と有資格者になる。有資格者は一つのプールで、配属先を取り合う。

| 資格・許可（ゲーム内表記） | 必要になる場面 |
|---|---|
| 劇物の取扱責任者 | 酸・アルカリ（劇物）の小分け販売・製造 |
| 危険物の取扱者 | 一部の薬品の大量貯蔵 |
| フォークリフト運転技能講習 | フォークリフト |
| 玉掛け・クレーン運転 | 天井クレーン・ユニック車 |
| 大型免許・けん引 | ウイング車・大型タンクローリー |
| 水質の公害防止管理者 | 大型の排水処理設備 |
| 分析の熟練者 | 上位の分析機器の能力を引き出す |
| 添加物製造の許可（事業所単位） | 食品添加物グレードの製造 |

**安全**：保護具・安全教育・防液堤・スクラバーで「安全度」が上がる。安全度が高いと小さな全体倍率（無災害の励み）。低くても重い罰はなく、まれに「ヒヤリハット」で一時的に稼働率が下がる程度。

**受託製造（時代3〜）**：案件カードが届き、**7つの段階**を踏んで製品化する。

| 段階 | 消費・条件 | 失敗・分岐 |
|---|---|---|
| 1. ヒアリング | 営業の時間 | 原料・用途・荷姿が判明 |
| 2. 製造方法・規格の検討 | 研究pt、該当する分析機器の有無 | 機器が足りなければ保留（後で再開可） |
| 3. サンプル製造 | 小バッチ（製造能力を一時占有）＋分析 | — |

| 6. 製品化 | 原料調達・製造・分析。**専用ライン／専用設備**の新設を選べる（費用の一部を客が負担） | — |
| 7. 梱包・納入 | 指定の荷姿 | 完了 → **継続受託**として毎月の定期収入＋能力の一部を占有 |

案件の種類：希釈・調合・溶解／使用済み液からのメタル精製／小分け梱包／ポリ缶洗浄／その他薬品の製造／劇物・食品添加物の製造／小ロット製造／専用設備の改良・新設／**貯蔵出荷基地**（自社タンクを貸して保管料を得る）

- 受託は**余った能力をお金に換える**仕組み。洗缶ラインや分析室に余裕が出た瞬間が、受託の始めどき

### 3L. 経営（損益と再投資）

- **月次損益**（ゲーム内1か月 ≒ 実時間7分）をログに一行、詳細は経営タブで：
  `売上 ／ 原料費 ／ 容器費 ／ 運賃・燃料 ／ 給与 ／ 電力・水道 ／ 消耗品（RO膜・樹脂）／ 廃棄物処理費 ／ 受託収入 ／ 利益`
- 利益がそのまま現金になり、**再投資**（設備購入）に使う。これが中盤の基本ループ
- 製品ごとの**粗利**（1kgあたり・1便あたり）を表示し、「ポリ缶で細かく売るか、ローリーで大量に売るか」を判断できるようにする
- **設備融資**（時代2〜）：信用に応じて借入可。毎月一定額を返済。現金がマイナスでも倒産はせず、稼働率が下がるだけ（詰み防止）
- 大型設備には**工期**（実時間）がある。発注 → 建設中 → 稼働。待ち時間が「次の再訪の楽しみ」になる

## 8. 調整のための指標

- 各ボトルネック（§4）の**発生時刻**をシミュレータで計測し、目安から±30%以内に収める
- 「何も買えない時間」が連続30分（アクティブ中）を超えないこと
- 1つの打ち手で能力が伸びる幅は **×1.5〜×3**（小さすぎると手応えがなく、大きすぎると次の詰まりが即座に来る）
- 中盤（時代1〜4）が総プレイ時間の **約75%** を占めること

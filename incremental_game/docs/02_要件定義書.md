## 1. 目的と範囲

### 1.1 目的
- 塩化鉄の手作業製造から始まる**製造プロセスの発展**をモチーフに、宇宙規模まで到達するインクリメンタルゲームを作る
- 社内で実験的に公開し、遊びながら製造工程・化学に親しめるものにする

### 1.2 範囲
| 範囲内 | 範囲外 |
|---|---|
| ゲーム本体（静的 HTML/CSS/JS） | サーバ側処理・サーバ保存 |
| ブラウザ保存（localStorage）とエクスポート/インポート | ランキング・ユーザー間の比較 |
| 時代0〜6＋エンディング | 社史・会社固有のエピソード |
| 開発用 Python ツール（バランスシミュレータ・データ検証） | 周回要素（クリア後の追加として将来検討） |
| 別アプリから呼び出されるための最低限の作法（§5） | スマホ専用UI、多言語対応 |

### 1.3 用語
| 用語 | 意味 |
|---|---|
| ティック | 最小時間単位。**1ティック＝0.2秒（毎秒5ティック）** |
| 資源 | 数量と上限を持つもの（鉄くず・塩酸・円など） |
| 設備 | 建てるたびにコストが上がる建造物 |
| 人手 | 人口。配属して資源を生産する |
| 技術 | 研究ptで一度だけ取得する解放要素 |
| 改善 | 資源で一度だけ取得する恒久強化 |
| 時代 | 進行段階（0〜6）。画面には名称を表示しない |
| 開示 | 画面要素が条件を満たして初めて出現すること |

## 2. 機能要件

### 2.0 導入と画面の開示（FR-INT）
| ID | 要件 |
|---|---|
| FR-INT-01 | タイトル画面は持たない。初回起動時、黒地に一行「暗い。」とボタン〔手探りする〕だけを表示する |
| FR-INT-02 | 導入シーケンス（企画書 §3）はデータ（ステップ＝ログ文・出現ボタン・遷移条件）で定義し、文言を差し替え可能にする |
| FR-INT-03 | 画面要素は開示条件を満たすまで描画しない：資源欄 → 人数 → タブ（現場）→ 暦 → 作業メモ → 工程図 → 他タブ…の順 |
| FR-INT-04 | 要素の開示はフェードイン（0.5〜1秒）。設定で演出OFF可 |
| FR-INT-05 | 未判明の資源は仮の名前（`? 液`、`緑の液`）で表示し、条件達成で正式名称に置き換える |
| FR-INT-06 | 60秒無操作の場合、次の行動を示唆するヒントを**ログに1行だけ**出す（ポップアップは出さない） |
| FR-INT-07 | 時代ごとに配色・文体が変わる（暗がり：黒／工場：灰白／星：紺）。時代名そのものは表示しない |
| FR-INT-08 | エンディング後は画面が暗転し「暗い。」〔沈める〕だけが残る。押すとクレジットと統計を表示 |

### 2.0a 最初の15分のフック（FR-HOK）
呼び出し元アプリのボタン「タイキ薬品工業　ミニゲーム」から開かれる前提で、最初は小さなミニゲームに見せ、約15分で奥行きに気づかせる（企画書 §3.5）。

| ID | 要件 |
|---|---|
| FR-HOK-01 | 開始〜約12分は、手作業・人手・釜の範囲の語彙と画面要素だけを出す。宇宙・恒星などの語は出さない |
| FR-HOK-02 | 12〜15分（ふつうの操作ペース）で次の3つが**ほぼ同時期**に起きるよう数値を調整する：現場タブに未解放設備の名前が灰色で並ぶ（ベルトコンベア・自動洗缶ライン・フォークリフト・天井クレーン・タンクローリー・分析室・純水装置 など）／技術画面の開示／ログ「夜、釜の液面に星が映っていた。」 |
| FR-HOK-03 | 未解放の設備・技術は**名前だけ**（灰色・説明なし・コスト非表示）表示し、奥行きを見せる。技術には時代5〜6の名前を少なくとも3つ含める |
| FR-HOK-06 | 画面上部の小さなタイトル表記は「タイキ薬品工業　ミニゲーム」。時代5で「ミニ」に取り消し線、時代6で「ミニ」が消える（設定でOFF可） |
| FR-HOK-04 | 約15分で作業メモ（次の目標）を開示し、ログに一度だけ「留守のあいだも、釜は溶かし続ける。」と出してオフライン進行を知らせる |
| FR-HOK-05 | フック関連の出来事の発生時刻（開始からの経過秒）を統計に記録し、テストで確認できるようにする |

### 2.4 人手と配属（FR-STF）
| ID | 要件 |
|---|---|
| FR-STF-01 | 人数の上限は住居系設備で決まる。上限に空きがあり信用が条件を満たせば、一定間隔で1人ずつ増える |
| FR-STF-02 | 人手は毎秒給与（円）を消費する。円が0になると全体の生産効率が下がる。人手が減ることはない |
| FR-STF-03 | 配属：溶解／回収／運転／充填／洗缶／荷役／分析／調合／物流（運転手・配車）／営業／研究／（時代5〜）宇宙作業。時代0〜1では「手伝い」とだけ表示 |
| FR-STF-07 | 資格：人手を講習に出す（時間＋円）と有資格者になる。有資格者でなければ動かせない設備がある（劇物・フォークリフト・玉掛け/クレーン・大型免許・排水の管理者 等。03 §3J） |
| FR-STF-04 | 配属は＋／−と一括（＋5、全員、解除）で変更できる |
| FR-STF-05 | 時代2以降、計装・自動化により「配属不要の設備」が増え、人手は研究・品質・物流に回っていく（自動化の手応え） |
| FR-STF-06 | 人数が多くなったら「班」単位（1班＝100人）で集約表示する |

### 2.5 技術（FR-TEC）
| ID | 要件 |
|---|---|
| FR-TEC-01 | 研究pt（＋一部資源）で取得し、設備・配属・改善・時代を解放する |
| FR-TEC-02 | 前提技術を持つツリー構造（初版約60件） |
| FR-TEC-03 | 取得済み・取得可能・未解放（名前だけ見える）を区別して表示する |
| FR-TEC-04 | 各技術に短い化学のフレーバーテキストを付ける |

技術ツリーの幹（例）：
`酸の扱い → 換気 → 塩素化 → 希釈 → 比重 → 分析 → 濃縮 → 脱銅 → 循環 → 凝集とシリカ → 計装 → 連続運転 → 純水 → 尿素の溶解 → 多項目分析 → 充填と荷姿 → 調合 → 尿素合成 → 物質収支 → 推進剤 → 宇宙冶金 → 大気化学 → 核融合 → 恒星元素合成 → 星間化学 → 宇宙反応工学`

### 2.6 改善（FR-UPG）
| ID | 要件 |
|---|---|
| FR-UPG-01 | 一度だけ購入できる恒久強化（初版約80件）。例：「厚手の手袋」溶解+50%／「タンクの蓋」上限+25%／「比重計」品質+10% |
| FR-UPG-02 | 効果は乗算または加算をデータで指定する |
| FR-UPG-03 | 購入済みの一覧を見られる |

### 2.7 取引（FR-TRD）
| ID | 要件 |
|---|---|
| FR-TRD-01 | 製品は「出荷」で円に換える。物流の配属・設備で自動出荷 |
| FR-TRD-02 | 取引先ごとに欲しい製品・単価・信用条件を持つ。信用が上がると単価・量が改善 |
| FR-TRD-03 | 季節で需要が変わる：夏＝凝集剤↑、冬＝尿素水↑ |
| FR-TRD-04 | 取引先の例：浄水場・下水処理場（凝集剤）、電子部品の工場（エッチング用の塩化第二鉄液。使用済み液を返してくる）、運送会社（尿素水）、農家（ポリシリカ鉄の汚泥が田畑に還る）、食品工場（調合品） |
| FR-TRD-05 | 時代6では異星の商会が取引先に加わる |
| FR-TRD-06 | 荷姿の段階（手渡し→ポリ缶→BIB→ドラム→コンテナ→ローリー→軌道輸送→恒星間輸送）で1回の出荷上限が増える |

### 2.8 調合台（FR-MIX、時代1〜）
| ID | 要件 |
|---|---|
| FR-MIX-01 | 仕入れ薬品と純水で、希釈・混合・溶解・小分けを行い多品目を作れる |

## 6. 受け入れ基準

1. 新規開始からエンディングまで通しでプレイでき、詰みがない
2. `simulate.py` で3スタイルすべてが §4.1 の目標範囲内でクリアする
3. 社内テストプレイヤーの実測クリア日数が 5〜14日に収まる
4. 旧バージョンのセーブデータが最新版で読み込める
5. 2時間連続で開いていても重くならない（メモリが増え続けない）
6. 社名はタイトル表記のみ。人名・地名・商標（AdBlue® 等）を含まない
7. 説明なしで導入シーケンス（〔釜を据える〕まで）を、テストプレイヤー全員が15分以内に突破できる
8. 別アプリから iframe／リンクで呼び出して動作する
9. テストプレイヤーが、ふつうのペースで12〜18分の間にフック（FR-HOK-02）に到達する。15分以上遊んだ人の過半数が、翌日以降もう一度開く

## 7. リスクと対策

| リスク | 対策 |
|---|---|
| 進行が速すぎる/遅すぎる | シミュレータと社内テストで調整。全パラメータは JSON で変更可 |
| 説明がなく初見で迷う | 60秒無操作ヒント（FR-INT-06）。テストで突破時間を計測 |
| JS と Python の計算がずれる | 式を単純に保ち、両者の一致テストを用意 |
| 後半の数値が巨大で分かりにくい | 命数表示＋「前回比×何倍」の表示で成長を実感させる |
| セーブ消失（ブラウザのデータ削除など） | エクスポート機能と、設定画面での定期エクスポートの案内 |

## 1. コンセプト

**「暗がりに、釜がひとつ。」**

プレイヤーは何も知らされずに始まる。画面にあるのは一行の文章と、ボタンがひとつだけ。
押すと、鉄くずが酸に沈み、泡が立ち、液の色が変わる。
溶かす量が増え、工程が増え、液は赤くなり、濃くなり、廃液は再生され、やがて尿素水がタンクローリーで運ばれていく。
同じ「溶かす・反応させる・精製する・詰める・届ける」が、月で、金星の雲で、恒星の炉で繰り返される。
最後に辿り着くのは宇宙規模の釜。そして画面は再び暗くなり、ボタンがひとつだけ残る。

### 設計の柱
1. **語らない**：ログに短い文が流れるだけ。状況はプレイヤーが察する
2. **製造プロセスが主役**：進行＝工程が一段ずつ増え、つながり、自動化され、巨大化していくこと
3. **化学は本物**：鉄＋塩酸で泡（水素）が出て液はうすい緑、塩素化で赤褐色、尿素水は32.5%…ゲーム的に誇張はしても嘘はつかない
4. **固有名詞はタイトルだけ**：社名はタイトルにのみ使う。ゲーム本編に人名・地名・商標は登場しない
5. **中盤が肝**：手作業 → 道具 → 機械 → 自動化。お金を稼いで再投資し、詰まりを一つずつ解いていく過程を、異常なほど綿密に描く（`03_中盤プロセス設計書.md`）

## 3.5 最初の15分の体験設計 ―「ミニゲームのはずが、何か違う」

社内アプリには **「タイキ薬品工業　ミニゲーム」** というボタンがひっそり置かれる（ボタンは呼び出し元アプリ側で用意）。
押した人は「創業当時をゲームにした、ちょっとしたクリックもの」と受け取る。**その思い込みを15分かけて静かに裏切る**のが、この作品の一番の仕掛け。

| 経過 | プレイヤーの認識 | 画面で起きること | 仕込み |
|---|---|---|---|
| 0〜3分 | 「ああ、創業期の手作業ね。素朴なクリックゲーム」 | 暗い画面・ボタン1つ・短文。釘を拾って酸に沈める | 期待どおりの小ささ。わざと地味に |
| 3〜7分 | 「売れた。人を呼べる。まあこんなものか」 | 円・人手・釜。数字が少しずつ増える | 「泡に火を近づけると、ぽんと鳴った。」（何の役にも立たない一文＝伏線） |
| 7〜12分 | 「あれ、意外とやることがある」 | 〔釜を据える〕でタブが出現。設備・配属。勝手に増えていく | 画面がミニゲームの枠を超えて広がり始める |
| **12〜15分** | **「……ん？　これ、どこまで行くの？」** | ①現場タブに、まだ買えない設備の名前が灰色で並ぶ：**ベルトコンベア、自動洗缶ライン、フォークリフト、天井クレーン、タンクローリー、分析室、純水装置…**（ミニゲームにタンクローリー？）／②技術画面が開き、ツリーの奥に名前だけ見える項目：「濃縮」「脱銅」「超純水」…その先に「推進剤」「大気化学」「恒星元素合成」／③ログ：「夜、釜の液面に星が映っていた。」 | ここが**フック**。説明はしない。見えてしまった名前と一文だけで想像させる |
| 15分〜 | 「ちょっと先が気になる」 | 作業メモ（次の目標）が開示。オフライン進行の案内が一行だけ出る：「留守のあいだも、釜は溶かし続ける。」 | 閉じても進むと知らせ、「また開く」理由を残す |

**守ること**
- 15分までは「ミニゲーム」の顔を崩さない（宇宙・恒星の語は一切出さない。出すのは技術ツリーの奥の**名前だけ**）
- フックは押し付けない。気づかない人は気づかないまま普通に続けられる
- 1回目の離脱（閉じる）時点で「続きがある」ことだけは確実に伝わっている状態にする

## 4. 時代構成 ＝ 製造プロセスの発展段階

時代名は画面に出さない（内部名）。背景色・文体・ログの語彙で変化を感じさせる。

| 時代 | 内部名 | プロセスの発展 | 主な新資源 | 目安（累計・ふつう） |
|---|---|---|---|---|
| 0 | **暗がり** | 手で鉄くずを塩酸に沈める。一回ずつ | 鉄くず・塩酸・緑の液・円 | 〜10分 |
| 1 | **工房** | 人手と道具。ポリ缶・台車・軽トラ。原料の空き缶を手で洗って再利用。換気・スクラバー。劇物の資格を取り、酸・アルカリの小分けへ進出。反応槽と塩素化で塩化第二鉄液（緑→赤褐色） | 塩化第一鉄液・塩化第二鉄液・ポリ缶・技術・信用 | 〜7時間 |
| 2 | **工場** | 分析室・パレット・フォークリフト・ラック・2t/4tトラック・洗缶機・排水処理（自社の液で処理）・**ベルトコンベアの小分けライン**・受変電・濃縮とボイラー・ドラム/コンテナ・天井クレーン | 電力・蒸気・品質・パレット・荷役・排水 | 〜2日 |
| 3 | **基地** | **タンクローリー**一式と大口受入・分析室のパンクと強化・脱銅とメタル精製・次亜塩素酸ソーダ・凝集剤群（PAC/ポリ硫酸第二鉄/ポリシリカ鉄）・純水装置と**尿素水**・自動洗缶ライン・配車・**受託製造** | 使用済み液・銅・純水・尿素水・輸送力・案件 | 〜4.5日 |
| 4 | **系** | 自動小分け装置・ロボットパレタイザ・自動倉庫・計装。新工場。超純水・食品添加物・高純度グレード。水素・酸・銅・水の**物質収支を閉じる** | 循環率・高純度品 | 〜6日 |
| 5 | **空** | 月の砂鉄を溶かす。金属小惑星を溶かす。**金星の雲（硫酸と塩化水素）から酸を回収**。捨て続けてきた水素がロケット燃料に | 月面鉄・軌道資材・ロケット燃料 | 〜7日 |
| 6 | **星** | 鉄は恒星が最後に作る元素。恒星炉で鉄を「生み」、星間雲の塩化水素と尿素を回収し、銀河規模で水を処理する | 恒星エネルギー・星間物質 | 〜8日 |
| E | **始まりの釜** | 宇宙規模の釜が完成。画面が暗転し、〔沈める〕だけが残る | — | **5〜14日** |

- **中盤（時代1〜4）が総プレイ時間の約75%**。宇宙・恒星は、それまでに作った仕組み（溶解・分析・純水・容器・輸送）が桁違いの規模で再演される「ご褒美の終盤」
- 中盤の詳細（サブシステム・共有の制約・ボトルネックの移り変わり・受託製造）は **`03_中盤プロセス設計書.md`** を参照

### 各段階で増える「プロセスの軸」
進行の手応えは、次の軸が一段ずつ伸びることで表現する。

| 軸 | 発展の例 |
|---|---|
| 規模 | 壺 → 釜 → 反応槽 → プラント → 軌道上プラント → 恒星炉 |
| 運転方式 | 手作業 → 人手で回すバッチ → 計装・自動運転 → 連続運転 → 無人運転 |
| 充填 | じょうご → ハンドポンプ → 半自動充填機 → ベルトコンベアの小分けライン → 自動小分け装置・ロボットパレタイザ |
| 容器 | 新品を買う → 手で洗う → 洗缶機 → 自動洗缶ライン → 洗缶受託 |
| 荷役 | 手 → 台車 → ハンドリフト → フォークリフト・ラック → 天井クレーン → 自動倉庫 |
| 品質 | 目視（色）→ 比重計 → 屈折率計 → 原子吸光・イオンクロマト・ICP・FT-IR → 高純水・超純水 → 宇宙規格 |
| 濃度・グレード | 薄い液 → 濃縮 → 高濃度グレード（40/42/47/50°Bé 相当）|
| 循環 | 廃液は捨てる → 引き取って再生 → 銅回収 → 物質収支を閉じる |
| 荷姿・輸送 | 手渡し → ポリ缶 → BIB → ドラム → コンテナ → ローリー → 軌道輸送 → 恒星間輸送 |
| 製品・分野 | 鉄液 → 酸・アルカリ小分け → 凝集剤・消毒剤（水処理）→ エッチング液と銅（電子）→ 尿素水（物流）→ 調合品・食品添加物 → 受託製造・受託分析・洗缶・保管 → 高純度品 |

## 8. テキストのトーン

- 暗がり〜工房：短文・体言止め。「泡が立つ。」「液が、赤い。」
- 工場〜ライン：作業記録調。「濃縮第3槽、比重良好。」
- 系〜空：少し詩的に。「金星の雲は硫酸と塩化水素でできている。仕入れ先が一つ増えた。」
- 星：短文に回帰。「鉄は、星が最後に作るもの。」「ずっと、星の灰を溶かしていた。」
- 最後：「暗い。」〔沈める〕

## 11. 未確定事項

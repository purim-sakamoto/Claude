# 企画書：『金物から星まで』（仮題）

> ブラウザで遊ぶ放置・インクリメンタルゲーム（Kittens Game 型）
> 社内システム組み込み用 / 想定クリア期間 5〜14日

---

## 1. コンセプト

**「手作業で金物を塩酸に溶かした一つの釜が、やがて宇宙を回す反応槽になる」**

創業期の手仕事から始まり、プラント化 → 化成品・環境製品（尿素水など）→ 全国・海外 → 宇宙 → 恒星・銀河スケールへと、
**同じ「溶かす・反応させる・届ける」という営み**のまま規模だけが天文学的に膨らんでいく物語。

- 会社の歩みを"下敷き"にするが、**実在の人物名・年号・社名・取引先は出さない**（過度に寄せない）
- 化学的なネタは「だいたい本当」を基本にする（鉄＋塩酸→塩化鉄＋水素、尿素水は約32.5%、金星の雲には塩化水素がある、鉄は恒星核融合の終着点、など）
- 最後は「宇宙そのものが巨大な反応槽だった」というオチで、創業の釜に回帰する

### タイトル案
| 案 | ねらい |
|---|---|
| **金物から星まで** | 素朴→壮大の落差が一目で伝わる（推し） |
| 塩鉄創世記 | 硬派・社史っぽい |
| リアクター・ガラクシア | カタカナでゲームらしく |
| ひとつの釜 | エンディングと呼応 |

## 3. 時代構成とボリューム

| 時代 | 名称 | テーマ（ざっくり） | 主な新資源 | 目安時間（累計） |
|---|---|---|---|---|
| 0 | **手仕事の時代** | 金物を塩酸に手で溶かし、塩化鉄液を作って売る | 円・金物・塩酸・塩化鉄液 | 〜1時間 |

| 2 | **プラントの時代** | 反応槽・塩素化設備・タンクヤード、品質管理 | 電力・鋼材・塩化第二鉄（凝集剤） | 〜1.5日 |
| 3 | **環境と物流の時代** | 水処理薬剤、純水、尿素水、タンクローリー網 | 純水・アンモニア・尿素・尿素水・輸送力 | 〜3.5日 |
| 4 | **全国・世界の時代** | 拠点展開、港湾、海外工場、研究所 | 拠点・ブランド | 〜5.5日 |
| 5 | **宇宙事業部** | 月の砂鉄、金属小惑星、金星の雲から塩化水素回収 | 月面鉄・軌道資材・ロケット燃料（水素） | 〜8.5日 |

## 4. ゲームループ

```
 [資源を作る] → [売る/加工する] → [設備を建てる・社員を雇う]
       ↑                                   ↓
 [改善提案で効率UP] ← [技術開発で解放] ← [研究ptがたまる]
       ↓
 [上限（タンク）に当たる] → [倉庫を建てる or 次の工程へ変換] → 次の時代へ
```

- **短期（数分）**：上限が埋まる前に変換・建設する、配属を調整する
- **中期（数時間）**：次の技術・改善提案を狙って研究ptをためる
- **長期（日単位）**：時代の壁（メガ設備・大型技術）を越える

## 5. 世界観・テキストの方針

- 主人公は「あなた（創業者/経営者）」。社名はゲーム開始時に入力（既定値：「〇〇化学（仮）」）
- 時代が進むごとに **「社史」タブに年表が1行ずつ追加**される（ゲーム内の架空の年表）
- 実在社名・製品商標は使わない（例：「AdBlue」は使わず「**高品位尿素水**」と表記）
- 実際の社史エピソードを入れたい場合は、テキストをデータファイルで差し替えられるようにする（運用側で調整可能）
- トーン：ちょっとユーモア、でも化学と現場へのリスペクトは崩さない
  - 例：「金物を塩酸に入れた。泡が出た。これは……水素？　とりあえず換気。」
  - 例（宇宙期）：「金星の雲は硫酸と塩化水素でできている。営業部は"仕入れ先"と呼び始めた。」
  - 例（終盤）：「鉄は、星が最後に作る元素だ。私たちは、ずっと星の灰を溶かしていた。」

## 1. コンセプト

**「暗がりに、釜がひとつ。」**

プレイヤーは何も知らされずに始まる。画面にあるのは一行の文章と、ボタンがひとつだけ。
押すと、鉄くずが酸に沈み、泡が立ち、液の色が変わる。
溶かす量が増え、工程が増え、液は赤くなり、濃くなり、廃液は再生され、やがて尿素水がタンクローリーで運ばれていく。
同じ「溶かす・反応させる・精製する・詰める・届ける」が、月で、金星の雲で、恒星の炉で繰り返される。
最後に辿り着くのは宇宙規模の釜。そして画面は再び暗くなり、ボタンがひとつだけ残る。

### 設計の柱
1. **語らない**：ログに短い文が流れるだけ。状況はプレイヤーが察する
2. **製造プロセスが主役**：進行＝工程が一段ずつ増え、つながり、自動化され、巨大化していくこと
3. **化学は本物**：鉄＋塩酸で泡（水素）が出て液はうすい緑、塩素化で赤褐色、尿素水は32.5%…ゲーム的に誇張はしても嘘はつかない
4. **固有名詞を出さない**：会社名・人名・地名・商標は登場しない

## 3. 導入シーケンス（ドラフト）

黒地に白い文字。ログとボタン1つだけ。資源欄・タブは**まだ存在しない**。

| # | ログ | 出現するボタン | 何が開示されるか |
|---|---|---|---|
| 1 | 暗い。 | 〔手探りする〕 | — |
| 2 | 冷たい。釘が一本。 | 〔拾う〕 | 資源欄：`鉄くず 1` |
| 3 | 鼻を刺す匂い。壺がある。 | 〔沈める〕 | `? 液`（中身不明の酸） |
| 4 | 泡が立つ。釘が、細くなっていく。 | （数秒待つ） | 初の「時間で進む」体験 |
| 5 | 液が、うすい緑に染まった。 | 〔拾う〕〔沈める〕 | `緑の液 1` |
| 6 | 戸を叩く音。「その緑の液、譲ってもらえないか」 | 〔渡す〕 | `円` |
| 7 | 硬貨が手に残る。 | 〔酸を買う〕 | `? 液` → `塩酸` と判明 |
| 8 | 泡に火を近づけると、ぽんと鳴った。 | — | 水素の示唆（資源化はずっと後） |

- 時代1で `緑の液` が `塩化第一鉄液` に置き換わる（「測ってみると、それは塩化第一鉄だった。」）

## 3.5 最初の15分の体験設計 ―「ミニゲームのはずが、何か違う」

社内アプリには **「タイキ薬品工業　ミニゲーム」** というボタンがひっそり置かれる（ボタンは呼び出し元アプリ側で用意。ゲーム内には社名を出さない）。
押した人は「創業当時をゲームにした、ちょっとしたクリックもの」と受け取る。**その思い込みを15分かけて静かに裏切る**のが、この作品の一番の仕掛け。

| 経過 | プレイヤーの認識 | 画面で起きること | 仕込み |
|---|---|---|---|
| 0〜3分 | 「ああ、創業期の手作業ね。素朴なクリックゲーム」 | 暗い画面・ボタン1つ・短文。釘を拾って酸に沈める | 期待どおりの小ささ。わざと地味に |
| 3〜7分 | 「売れた。人を呼べる。まあこんなものか」 | 円・人手・釜。数字が少しずつ増える | 「泡に火を近づけると、ぽんと鳴った。」（何の役にも立たない一文＝伏線） |
| 7〜12分 | 「あれ、意外とやることがある」 | 〔釜を据える〕でタブが出現。設備・配属。勝手に増えていく | 画面がミニゲームの枠を超えて広がり始める |
| **12〜15分** | **「……ん？　これ、どこまで行くの？」** | ①液が緑から**赤褐色**に変わる（塩素化）／②技術画面が開き、ツリーの奥に**名前だけ見える**項目が並ぶ：「比重」「濃縮」「循環」…その先に「推進剤」「大気化学」「恒星元素合成」／③ログ：「夜、釜の液面に星が映っていた。」 | ここが**フック**。説明はしない。見えてしまった名前と一文だけで想像させる |
| 15分〜 | 「ちょっと先が気になる」 | 作業メモ（次の目標）が開示。オフライン進行の案内が一行だけ出る：「留守のあいだも、釜は溶かし続ける。」 | 閉じても進むと知らせ、「また開く」理由を残す |

**守ること**
- 15分までは「ミニゲーム」の顔を崩さない（宇宙・恒星の語は一切出さない。出すのは技術ツリーの奥の**名前だけ**）
- フックは押し付けない。気づかない人は気づかないまま普通に続けられる
- 1回目の離脱（閉じる）時点で「続きがある」ことだけは確実に伝わっている状態にする

## 4. 時代構成 ＝ 製造プロセスの発展段階

時代名は画面に出さない（内部名）。背景色・文体・ログの語彙で変化を感じさせる。

| 時代 | 内部名 | プロセスの発展 | 主な新資源 | 目安（累計・ふつう） |
|---|---|---|---|---|
| 0 | **暗がり** | 手で鉄くずを塩酸に沈める。一回ずつのバッチ | 鉄くず・塩酸・緑の液・円 | 〜10分 |
| 1 | **工房** | 釜を増やす・人手で回す → 換気 → **塩素化**で塩化第二鉄液（緑→赤褐色）。酸の希釈・小分けを覚える | 塩化第一鉄液・塩化第二鉄液・技術 | 〜半日 |
| 2 | **工場** | **分析**で品質を測る → **濃縮**で濃度グレード（ボーメ度）を上げる → 使用済み液を引き取り**脱銅・再生**（循環）→ シリカと鉄の**凝集剤**（ポリシリカ鉄）。バッチから連続運転へ | 電力・品質・使用済み液・銅・ポリシリカ鉄 | 〜1.5日 |
| 3 | **ライン** | **純水** → **尿素の溶解** → 32.5%に合わせる → 約20項目の分析 → **充填**。荷姿がポリ缶→バッグインボックス→ドラム→コンテナ→ローリーへ大型化。調合（希釈・混合・溶解・小分け）で多品目化 | 純水・尿素・尿素水（AUS32）・輸送力・各種薬品 | 〜3.5日 |
| 4 | **系** | 工程同士がつながる：副産物が原料になり、廃液が資源になる。塩酸・水素・銅・水の**物質収支を閉じる**ことが目標。尿素の自社合成（アンモニア＋CO₂） | 循環率・アンモニア・CO₂ | 〜5.5日 |
| 5 | **空** | 月の砂鉄を溶かす。金属小惑星を溶かす。**金星の雲（硫酸と塩化水素）から酸を回収**。捨て続けてきた水素がロケット燃料に | 月面鉄・軌道資材・ロケット燃料 | 〜8.5日 |
| 6 | **星** | 鉄は恒星が最後に作る元素。恒星炉で鉄を「生み」、星間雲の塩化水素と尿素を回収し、銀河規模で水を処理する | 恒星エネルギー・星間物質 | 〜11日 |
| E | **始まりの釜** | 宇宙規模の釜が完成。画面が暗転し、〔沈める〕だけが残る | — | **5〜14日** |

### 各段階で増える「プロセスの軸」
進行の手応えは、次の軸が一段ずつ伸びることで表現する。

| 軸 | 発展の例 |
|---|---|
| 規模 | 壺 → 釜 → 反応槽 → プラント → 軌道上プラント → 恒星炉 |
| 運転方式 | 手作業 → 人手で回すバッチ → 計装・自動運転 → 連続運転 → 無人運転 |
| 品質 | 目視（色）→ 比重計 → 分析室 → 多項目分析・規格適合 → 宇宙規格 |
| 濃度・グレード | 薄い液 → 濃縮 → 高濃度グレード（40/42/47/50°Bé 相当）|
| 循環 | 廃液は捨てる → 引き取って再生 → 銅回収 → 物質収支を閉じる |
| 荷姿・輸送 | 手渡し → ポリ缶 → BIB → ドラム → コンテナ → ローリー → 軌道輸送 → 恒星間輸送 |
| 製品数 | 1品目 → 鉄系2品目 → 凝集剤 → 尿素水 → 調合品多数 |

## 7. ゲームループ

```
 [溶かす] → [加工・精製する] → [詰めて届ける] → [設備・人を増やす]
     ↑                                               ↓
 [改善] ← [技術] ← [研究ptがたまる]       [ボトルネック発見（工程図）]
     ↓
 [上限に当たる] → [タンク or 次の工程] → 画面がまた一つ開ける
```

## 8. テキストのトーン

- 暗がり〜工房：短文・体言止め。「泡が立つ。」「液が、赤い。」
- 工場〜ライン：作業記録調。「濃縮第3槽、比重良好。」
- 系〜空：少し詩的に。「金星の雲は硫酸と塩化水素でできている。仕入れ先が一つ増えた。」
- 星：短文に回帰。「鉄は、星が最後に作るもの。」「ずっと、星の灰を溶かしていた。」
- 最後：「暗い。」〔沈める〕
